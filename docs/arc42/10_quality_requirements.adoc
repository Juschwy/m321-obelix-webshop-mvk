== Quality Requirements

This chapter captures **relevant quality requirements** and associated scenarios.

'''

=== Quality Requirements Overview

[cols="1,2",options="header"]
|===
|Category / Topic |Short Description

|Simplicity of Deployment
|Single VM with Docker Compose; setup within <30 minutes on a fresh VM via cloud-init.

|Observability
|Prometheus scrapes all backend services; Zipkin collects traces; Grafana dashboards load in <5s.

|Documentation Quality
|arc42 chapters filled; OpenAPI has descriptions+examples for all properties; diagrams embedded.

|CI Reliability
|PR builds succeed deterministically; main deployments complete in <10 minutes.

|Performance (Dev/Test)
|API endpoints respond in <500ms under light load (<20 RPS) on the single VM.

|Security (Dev/Test)
|No auth per assignment; VM has only required ports open; secrets handled in CI securely.
|===

'''
