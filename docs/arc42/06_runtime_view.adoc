== Runtime View

This chapter describes **runtime behavior and interactions** between the building blocks.
It focuses on **architecturally relevant scenarios** and is intentionally limited
to a small, representative set.

Each scenario should explain *how* building blocks collaborate at runtime.

=== How to use this chapter

* Add **only relevant scenarios** (important, risky, or representative).
* Prefer **clarity over completeness**.
* Each scenario should be understandable **without reading the source code**.
* Use **PlantUML** for diagrams where possible.
